# Cold Outreach 2026 — библиотека исследования

[Открыть сайт](https://wwwparser.github.io/cold-outreach-research-2026/)

Учебная библиотека по B2B email и CRM-маркетингу: 19 глав, введение и 5 приложений, PDF-книга, 75 кейсов, шаблоны писем и цепочек, поиск и прогресс чтения.

Дополнения октября 2026: отдельный разбор десяти Telegram-каналов с каталогом 107 публикаций и аналитика по 50 видео 2025–2026 годов с темами и таймкодами.

Сайт работает как обычная статическая страница: HTML, CSS и JavaScript. Сборка и внешние API для чтения не нужны. Можно скачать репозиторий и открыть index.html. Прогресс и тема оформления хранятся локально в браузере.

## Состав публикации

В корне — готовый сайт, в research/ — тексты исследования, в book/ — главы, в downloads/ — PDF и каталоги CSV. GitHub Pages публикует ветку main из корня; .nojekyll отключает обработку Jekyll.

Исходные транскрипты, полные архивы Telegram, базы контактов, переписки, материалы коммерческого предложения и конфигурации доступа не включены. На сайте приведены выводы, краткие находки и ссылки на источники.

Кейсы и заявления источников сопровождаются ограничениями и не являются гарантией результата. Книга сохраняет редакцию сентября 2026; новые исследования опубликованы отдельными разделами. Дата публикации видео не обязательно совпадает с датой описанного эксперимента.
